# Stock Market Analysis of Apple from 1980 - 2021


## Using uv

### Advantages of uv
- It is a tool which replaces pip, venv
- Need not create a separate virutal environment, uv can handle it

### Installion
Windows

- Copy paste below command into your powershell

Powershell 
```
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```
If powershell is throwing execution policy error run below command and run uv installation command
```
Set-ExecutionPolicy RemoteSigned -scope CurrentUser
```
macOS/Linux:
Bash
```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Verify if the uv is installed
```
uv --version
```

### uv First steps
- Create a project folder
- Initialize: ```uv init```
- Add libraries: ``` uv add library_name```
